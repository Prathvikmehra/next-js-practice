# Home Hero Image Design

## Goal

Use the supplied college-supplies photo to fill the open space in the CampusMart home-page hero while keeping the full image visible, softening its corners, and preserving image clarity.

## Design

Keep the existing hero copy and calls to action on the left. Add the provided image on the right in a rounded panel, using contain sizing so the entire image remains visible without cropping. On narrow screens, stack the image below the text. Keep the change limited to the home page and use the existing styling and image tooling where practical.

## Alternatives considered

- Cropping the image to cover the panel would fill every pixel but hide part of the photo.
- A background image could compete with the hero copy and make the image harder to view clearly.

The approved layout is the two-column hero with the full image visible.
